# In-game Basic Attack stills

Drop English **Basic Attack** tooltip screenshots into the Pokémon folder. Images stay gitignored. `SKILLS.txt` is the capture checklist.

The Pokémon name is at the top left of each still. A long tooltip may need more than one still: `basic-attack-1.jpeg`, `basic-attack-2.jpeg`. A single still is `basic-attack.jpeg`.

Transcribe into `tools/community/move_descriptions.json` under the `basic attack` key, then curate.
